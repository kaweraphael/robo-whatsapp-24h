# Qual IA usar

A IA escreve as respostas. Troca em `config/robo.json` (campo `ia`) + a chave
no `.env`. Não muda nada no resto do robô.

| Provedor (`ia.provedor`) | Chave no `.env` | Onde pegar | Custo | Ouve áudio? |
|---|---|---|---|---|
| `gemini` (padrão) | `GEMINI_API_KEY` | https://aistudio.google.com/apikey | Tem plano grátis | Sim |
| `openai` | `OPENAI_API_KEY` | https://platform.openai.com/api-keys | Pago (pré-pago) | Sim |
| `anthropic` (Claude) | `ANTHROPIC_API_KEY` | https://console.anthropic.com/settings/keys | Pago (pré-pago) | Não |
| `openrouter` | `OPENROUTER_API_KEY` | https://openrouter.ai/keys | Pago, centenas de modelos numa chave | Não |
| `compativel` | `IA_API_KEY` + `IA_BASE_URL` | Groq, DeepSeek, Together, Ollama... | Depende | Não |

Quando a IA não ouve áudio, o robô pede com educação pro cliente escrever.

## Modelo (`ia.modelo`)

Se deixar vazio, usa o padrão de cada provedor:

- Gemini: `gemini-flash-lite-latest`. O nome com `-latest` sempre aponta pro
  mais novo, então o robô não quebra quando o Google aposenta um modelo.
  O Flash-Lite tem o limite grátis mais folgado.
- OpenAI: `gpt-5-mini`.
- Claude: `claude-haiku-5-5`.
- OpenRouter: `openrouter/auto` (ele escolhe).

`npm run checar -- ia` lista os modelos da sua conta e testa a conexão.

## Gemini grátis: o que ninguém fala

1. **Limite por dia.** O plano grátis tem limite de pedidos por minuto e por
   dia, que muda com o tempo e por modelo. Veja o seu em
   https://aistudio.google.com (Rate limits). Robô com muito volume estoura;
   aí o robô tenta 3 vezes e passa a conversa pra você.
2. **Seus dados.** No plano grátis, o Google pode usar o que você manda pra
   melhorar os produtos dele. Com conversa de cliente, o mais seguro é ativar
   o faturamento (paga só o que usar, é barato) e aí os dados deixam de ser
   usados.

## Testar antes de ligar no WhatsApp

```bash
npm run simular
npm run simular -- --lista --nome Ana --empresa "Pet da Ana" --cidade Londrina
```

Conversa no terminal com o seu atendente, usando a IA de verdade. Tente
quebrar: peça desconto, pergunte coisa fora do assunto, diga "não quero mais".
Ajuste `config/atendente.md` até ficar do jeito que você quer.
